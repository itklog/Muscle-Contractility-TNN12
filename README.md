## (c) Methods and R Commands
The analysis was performed using R. The `rentrez` package was used to retrieve gene and protein records from NCBI, while `ggplot2` was used to create the visualizations.
### Prerequisites
An internet connection is needed to retrieve records from NCBI. You may use the Posit cloud or install R and the required packages. 
```r
install.packages(c("rentrez", "ggplot2"))
library(rentrez)
library(ggplot2)
```
The complete, numbered script is provided in `analysis.R`. Run the script from the repository's root directory so that the output folders and file paths match those specified in the code.

### Step 1. Initialize Variables and Directory Structure
The gene symbol, transcript accession, ClinVar Variation ID, and assigned variant are defined as variables. The `data`, `results`, and `figures` directories are created to keep the downloaded sequence, analysis results, and generated figures separate.

**Expected output:** Three folders containing the files generated by the subsequent steps.

### Step 2. Retrieve and Verify Gene Metadata from NCBI
The script searches NCBI Gene for the human TNNI2 gene and checks the retrieved records to identify the exact gene symbol. The gene identifier, official name, chromosome, and assigned variant information are saved in `results/gene_summary.txt`.

**Expected output:** A text file containing the retrieved gene metadata.

### Step 3. Retrieve the Reference Protein Sequence
The transcript record `NM_003282.4` is retrieved from NCBI Nucleotide. The script extracts the annotated RefSeq protein accession and uses it to download the corresponding protein sequence in FASTA format.

**Expected output:**
- `data/TNNI2_protein.fasta`
- `results/protein_accession.txt`
The FASTA file contains the reference protein sequence used in the subsequent analysis.

### Step 4. Analyze Protein Length and Amino-Acid Composition
The FASTA file is read into R, and the amino-acid sequence is extracted. The total number of residues is calculated, and the occurrences of the 20 standard amino acids are counted.

**Expected output:** `results/amino_acid_composition.csv`, which contains each standard amino acid and its corresponding count.

### Step 5. Visualize Amino-Acid Composition
The `ggplot2` package is used to generate a bar chart showing the number of occurrences of each standard amino acid in the reference protein.

**Expected output:** `figures/01_amino_acid_composition.png`.
The chart provides a basic description of the protein's amino-acid composition but does not establish its three-dimensional structure or the functional effects of the assigned variant.

### Step 6. Visualize the Variant Position
The amino-acid position is extracted from `p.Arg156Ter` and checked against the reference protein length. A linear map is generated to mark position 156 along the reference sequence.

**Expected output:** `figures/02_variant_position.png`.
This figure shows the location of the premature termination codon relative to the reference protein. It does not represent a three-dimensional structural model or confirm that a truncated protein is produced.

### Step 7. Display the Analysis Summary
The script prints the gene symbol, NCBI Gene ID, transcript accession, protein accession, protein length, variant position, and ClinVar Variation ID in the R console.

**Expected output:** A summary of the retrieved information and a list of the files generated by the script.

## (e) Variant Interpretation
### Variant Consequence

The assigned variant, `p.Arg156Ter`, is a nonsense or stop-gain variant corresponding to the nucleotide substitution `c.466C>T`. This change converts the reference arginine codon (CGA) into a premature termination codon (TGA) at amino-acid position 156.

### Possible Molecular Effects

TNNI2 encodes fast skeletal muscle troponin I, an inhibitory subunit of the troponin complex that helps regulate actin–myosin interactions during muscle contraction and relaxation. The premature stop codon may result in a shortened protein or cause the transcript to be degraded through nonsense-mediated mRNA decay (NMD).

If the normal amount or function of troponin I is disrupted, the regulation of skeletal muscle contraction could be affected. However, the exact molecular mechanism cannot be established from the sequence change alone.

### Clinical Significance

ClinVar classifies Variation ID 12436 as Pathogenic and associates the variant with distal arthrogryposis type 2B1 (DA2B1). 

## (f) Limitations and Proposed Validation Experiment

### Limitations

This analysis relies on reference sequence annotations and existing database records. It does not directly measure patient-specific gene expression, transcript degradation, protein abundance, three-dimensional structural changes, or muscle contractility. The linear protein map identifies the variant position but cannot confirm the production or functional effects of a truncated protein.

### Proposed Validation Experiment

An in vitro actomyosin ATPase assay using reconstituted thin filaments containing wild-type and variant troponin complexes could help test the proposed mechanism. ATPase activity could be measured at different calcium concentrations to determine whether the variant changes the regulation of actin–myosin interactions. A sliding filament assay could also be used to examine filament movement. Appropriate controls and replicate measurements would be needed to determine whether any observed differences are reproducible.
